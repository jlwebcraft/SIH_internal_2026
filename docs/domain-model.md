# Preliminary Domain Entities

The following preliminary domain entities define the starting vocabulary for the product. They do not represent finalized database tables or implementation classes yet.

- User
- Role
- Supplier
- SupplierPerformance
- Material
- Product
- BillOfMaterial
- Inventory
- PurchaseOrder
- PurchaseOrderItem
- Delivery
- Prediction
- RiskEvent
- Recommendation
- Simulation
